# Security Policy

## Supported Versions
We currently support the latest release and the `main` branch of Kräuter-WG.

## Reporting a Vulnerability
If you discover a security vulnerability within the Kräuter-WG Web UI or ESP32 code, please **DO NOT** open a public issue. 

Instead, please contact the maintainers directly via private message or email. We take security seriously and will try to address the issue as quickly as possible before making it public.
