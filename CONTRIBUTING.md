# Contributing to Kräuter-WG 🌿

First off, thank you for considering contributing to the project! I love seeing the community build and improve this system.

## How to Contribute
1. **Fork the repo** and create your feature branch from `main`.
2. **Test your code!** Make sure your changes don't break the existing Smart Rules, UI, or sensor readings.
3. **Keep it clean:** Write clear commit messages and document any new features or variables.
4. **Open a Pull Request (PR):** Describe exactly what you changed, why you changed it, and how you tested it.

## Bug Reports & Feature Requests
Before opening a new issue, please check if it has already been reported. When creating an issue, please use the provided Issue Templates and fill out all the necessary information.
